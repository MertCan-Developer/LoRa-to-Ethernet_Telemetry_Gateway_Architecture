# LoRa-to-Ethernet_Telemetry_Gateway_Architecture
This repository contains code that enables the transfer of sensor data between two Lora modules and the display of that data on the receiver device's screen module. And I used Packet Sender application to receive data from the system to the laptop through the TCP.
